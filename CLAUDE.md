# CLAUDE.md — Instructions for AI coding assistants working on MicroLearn

## What this project is
An IoT camera attachment for a lab microscope. The approved scope streams live video from the Pi to the hosted UI, analyzes captured stills using backend and inference hosted together on OCI Ampere A1, and supports structure/border selection and Gemini chat about selected regions. Read `docs/PRD.md`, `docs/ARCHITECTURE.md`, and `docs/TECH_STACK.md` before writing code.

## Hard constraints — do not violate these

1. **Use the selected cloud deployment roles.** Google AI Studio publishes the UI to Cloud Run (or its assigned custom `ai.studio` URL); one Oracle Cloud Infrastructure VM hosts backend and inference; Hugging Face stores separate dataset and model repositories; Google Colab is used for training; Gemini provides contextual chat through the OCI backend. These are design decisions, not evidence of deployed services. Verify container architecture, OCI capacity and idle-reclamation risk. Never expose Gemini or service credentials in browser code.
2. **Use the revised combined model scope.** Compact U-Net is selected to identify visible structures and predict cell boundaries; separation processing derives individual cells. Wall selection highlights the complete visible border of one cell without filling its interior. An internal-structure click selects that individual supported region. Stained onion is the target preparation; exact stain, final classes, and separation method remain open. U-Net is selected but not trained or validated.
3. **Bind selection to real masks and the analyzed frame.** Issue 4 option 1 is approved: PNG structure-class and cell-ID masks plus JSON metadata. Preserve integer labels and frame/model/separation identity. Shared walls can belong to multiple cells: show candidate boundaries and use a second interior click to choose the cell. Mark clipped/uncertain boundaries as incomplete; do not invent closure or interpret a connected wall network as one cell border. Cell IDs are local to a prediction, not tracking across frames.
4. **Keep responsibilities explicit.** The Pi captures/streams and will capture requested stills; OCI coordinates capture, backend APIs, and model inference on the same VM; Gemini explains/chat; Colab trains. Do not move inference to the Pi or add unrelated infrastructure without a project decision. Do not add an unrelated database, business logic, or authentication without a project need.
5. **Use real results and reviewed content.** No dummy model, fake confidence, fixed hit circle, or prewritten region map may masquerade as segmentation. Use reviewed training masks to teach the model and actual inference for new images. Show explicit unavailable/uncertain states when evidence is missing. Never invent biology content or reviewer sign-off.
6. **Don't overstate what's built.** If asked to write documentation, status updates, or comments describing project state, describe only what actually exists in the code at that point — this project has a documented history of draft materials overstating readiness (e.g. claiming "AI segmentation" when only lookup-table matching existed), and that pattern should not be repeated in code comments or docs either.
7. **Integrate the real flow early.** Follow M0–M5 in `docs/IMPLEMENTATION_PLAN.md`: real capture, reviewed data, actual trained weights, early physical integration, improvement, and evaluation. Record evidence for each milestone and distinguish integration success from validated demo readiness. Do not use dummy outputs to claim progress.
8. **Use the approved capture-first interaction.** Show the continuously active WebRTC live preview (OCI signaling; coturn fallback on OCI) for positioning/focus; on **Capture**, send commands/status over WebRTC DataChannel and upload the still directly from Pi to OCI over HTTPS. OCI returns asynchronous inference job IDs/status; job state is in memory and lost jobs after restart require recapture. WebRTC and capture are selected but not implemented; current Pi code exposes MJPEG streaming and status only. Do not claim still capture, frame identity binding, or analysis is implemented until it is.
9. **Follow approved training/data choices.** Train compact U-Net in Colab, store dataset and weights in separate Hugging Face repositories, and use the image-level 70/30 split. Current local Roboflow export has 167 images and three semantic classes (cell walls, cytoplasm, nucleus); the first training script consumes that COCO export. These labels do not yet provide reviewed per-cell instance IDs. Uncertain pixels are ignore/unlabeled, not background. Numeric quality targets were dropped; do not invent threshold gates.
10. **Provide age-restricted contextual Gemini chat securely.** Gemini chat is for adults aged 18 or older only. Send text-only selected class/region, reviewed description, question, and chat history through OCI; do not send the image. Keep the key server-side. If Gemini fails, preserve the reviewed info card and show chat unavailable with Retry. Gemini must not fabricate segmentation or claim unsupported structures.

## Code style / structure expectations
- Keep capture, training/inference, and browser code clearly separated, with explicit data contracts between them.
- Keep PNG label masks and JSON metadata consistent with `docs/SCHEMA.md`. Training data and model artifacts are planned for separate Hugging Face repositories; secrets stay in backend deployment configuration. Do not introduce a database implicitly.
- Favor small, readable, well-commented functions over cleverness — this is a student project that faculty and teammates with varying experience levels will need to read and modify.

## When something in a request conflicts with the above
Flag it explicitly rather than silently implementing it. For example, if asked to add a login system or an unapproved persistent database, identify the scope change and clarify as needed. Cloud hosting and model/dataset storage are already approved in `docs/ARCHITECTURE.md`.

## Current evidence and remaining work
- React UI is in `microlearn/src`. No Pi service exists in this checkout yet.
- `dataset/train` contains 167 Roboflow COCO segmentation images and annotations for cell walls, cytoplasm, and nucleus.
- `training/train_unet.py` implements semantic segmentation training and a reproducible image-level 70/30 split; it has not completed a successful Colab run and has no resulting trained artifact yet.
- `microlearn/server.ts` includes health, capture-upload, text-chat, ICE credential, and signaling scaffolding. Inference intentionally reports unavailable until a compatible trained artifact and runtime are integrated. Cloud deployment is scaffolded but not deployed.
- Per-cell instance IDs, cell-border association, Pi WebRTC/capture service, deployed cloud, physical validation, and end-to-end evidence remain outstanding.
- `docs/IMPLEMENTATION_PLAN.md` records milestones and evidence requirements; no physical/model milestone is marked passed.
